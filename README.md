# Ibzen Launchpad

Act as an expert Full-Stack Developer and UI/UX Designer specializing in Next.js, Tailwind CSS, and modern, high-impact web aesthetics. I need you to build a single-page landing site for a student-led innovation and engineering initiative named "Ibzen".
About Ibzen:
Ibzen is dedicated to empowering school students through practical learning, career awareness, and future-ready skills. We host immersive two-day workshops introducing students to innovation, technology, engineering, financial literacy, problem-solving, and career guidance. We connect young learners with passionate engineering students and industry-inspired experiences. Our mission is to inspire the next generation of builders, leaders, and changemakers by fostering creativity, critical thinking, and an innovation-first mindset.
Strict Design Rules & Constraints:


NO IMAGES: You are strictly forbidden from using tags, placeholders, or background images. The entire aesthetic must be driven by exceptional typography, grid layouts, negative space, and CSS-based visual effects (glows, glassmorphism, borders).

Color Palette & Theme: The background must be a dark, blurry gradient inspired by the reference file "057C75E5-3E11-4F23-8495-B490D055838F.png". Implement a smooth vertical CSS gradient transitioning from deep pitch black at the top to a rich, dark navy blue at the bottom (e.g., bg-gradient-to-b from-[#050505] to-[#0A1128]).

Typography-First: Because there are no images, use a highly polished, modern sans-serif typeface (like Inter or Geist). Utilize varying font weights, tracking (letter spacing), and opacity (text-white/90, text-white/50) to establish a clear visual hierarchy.

Hero Section: The hero section must be highly prominent. The primary tagline on the home page must be exactly: "For the students, by the students." Make this typography massive, perhaps utilizing a subtle text-gradient or subtle text-shadow to make it pop against the dark blur background.

Required Sections:


Navigation: Minimalist top bar with a text-based "Ibzen" logo and simple links (About, Workshops, Mission).

Hero: Center-aligned, high-density typography featuring the tagline, a brief sub-headline summarizing the mission, and a primary CTA button (e.g., "Join a Workshop").

Mission/About: A clean, grid-based layout detailing the belief that "exposure creates confidence."

Core Pillars (The 2-Day Workshop): Use a CSS grid of bento-box style cards to display the core topics (Technology, Engineering, Financial Literacy, Problem-Solving). Use subtle CSS border-gradients and a glassmorphic background (e.g., bg-white/5 backdrop-blur-md) for these cards to add texture without using images.

Footer: Clean, simple footer with contact links and a copyright notice.

Deliverables:
Please provide the complete, production-ready code for this landing page. Provide the code using React (Next.js app router structure if applicable) and Tailwind CSS for styling. Ensure all components are fully responsive (mobile-first) and include subtle hover states and transitions for interactive elements.
